## 1. Evaluate the following limits (40 points, 5 each)

a) lim (x→0) sin 6x / tan 4x

b) lim (x→0) (1 − cos 3x) / x²

c) lim (x→0) [√(9 + x) − √(9 − 2x)] / (6x)

d) lim (x→3⁻) |x − 3| / (x² − 9) and lim (x→3) |x − 3| / (x² − 9)

e) lim (x→1⁺) [2/(x − 1) − 1/(x − 1)²]

f) lim (x→2) [1/(x + 3) − 1/5] / (x² − x − 2)

g) lim (x→∞) (3x² − x + 1) / (5 − 2x²)

h) lim (x→−∞) √(4x² + 1) / (3x − 2)

## 2. Find the discontinuities and explain (10 points)

f(x) =
- x + 3, x < −2
- 1, −2 ≤ x < 0
- x² + 2, 0 ≤ x < 1
- 5, x = 1
- 4 − x, x > 1

## 3. Find a and b so that f is continuous for all x (8 points)

f(x) =
- ax + b, x < −1
- 3 − x, −1 ≤ x ≤ 1
- ax² + b, x > 1

## 4. Asymptotes (6 points)

Find all vertical and horizontal asymptotes of y = (2x² + 1)/(x² − 4).

## 5. Using the definition of derivative, find f′(x). Then find the equation of the tangent line (24 points, 8 each)

a) f(x) = 3x² + 2x, tangent at x = 1

b) f(x) = 1/(2x + 3), tangent at x = −1

c) f(x) = √(2x + 1), tangent at x = 4

## 6. Using rules of differentiation find dy/dx (12 points, 3 each)

a) y = 3x⁴ − 2/x³ + 4√x − 7

b) y = (x² + 1)(x³ − 2x)

c) y = (x² − 3x)/(2x + 1)

d) Find y″ for y = x⁴ − 3x² + 1/x
