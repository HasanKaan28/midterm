## 1. Evaluate the following limits

a) lim (x→4) (√x − 2)/(x − 4)

b) lim (x→1) (x² + x − 2)/(x² − 1)

c) lim (x→0) x sin 2x / (1 − cos x)

d) lim (x→0) sin² 2x / (x tan 3x)

e) lim (x→(−1)⁺) (x − 2)/(x + 1)

f) lim (x→∞) [√(x² + 4x) − x]

g) lim (x→−∞) (5x³ − 2x)/(1 − 2x³)

h) lim (x→5) |x − 5|/(x² − 25)

i) lim (x→0) x² cos(1/x)

## 2. Continuity

a) f(x) = (x² − 9)/(x − 3) for x ≠ 3, and f(3) = a. Find a so that f is continuous at x = 3.

b) f(x) = x² − a for x < 2, and f(x) = ax + 1 for x ≥ 2. Find a so that f is continuous for all x.

c) Find the discontinuities of f(x) = (x − 1)/(x² − 1) and state the type of each.

d) Show that the equation x³ + x − 1 = 0 has a solution in the interval (0, 1).

## 3. Using the definition of derivative, find f′(x) and the tangent line

a) f(x) = x/(x + 1), tangent at x = 1

b) f(x) = x³ − 2x, tangent at x = 1

## 4. Using rules of differentiation find dy/dx

a) y = (√x + 2)(√x − 1)

b) y = (3x + 1)/(5x − 1)

c) y = ∛x + 5/∛x

## 5. Tangents and asymptotes

a) Find the points where the tangent line to y = x³ − 3x is horizontal.

b) Find all vertical and horizontal asymptotes of y = √(x² + 1)/x.
