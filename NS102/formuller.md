# NS102 Formül Sayfası (Bölüm 1–7)

g = 9,80 m/s². Açıların hepsi derece cinsinden.

## Bölüm 1: Birimler ve vektörler

- Birim çevirme: 1 km/h = 1/3,6 m/s. 1 m/s = 3,6 km/h.
- Bileşenler: Ax = A cos θ, Ay = A sin θ (θ, +x ekseninden saat yönünün tersine ölçülür).
- Büyüklük ve yön: A = √(Ax² + Ay²), tan θ = Ay / Ax. Çeyreği bileşenlerin işaretinden kontrol et.
- Toplama: Rx = Ax + Bx, Ry = Ay + By.
- Birim vektörler: **A** = Ax **î** + Ay **ĵ** + Az **k̂**.
- Skaler çarpım: **A**·**B** = AB cos φ = AxBx + AyBy + AzBz.
- İki vektör arası açı: cos φ = (**A**·**B**) / (AB).
- Vektörel çarpım büyüklüğü: |**A**×**B**| = AB sin φ. Yön: sağ el kuralı.
- Vektörel çarpım bileşenleri:
  - Cx = AyBz − AzBy
  - Cy = AzBx − AxBz
  - Cz = AxBy − AyBx
- **î**×**ĵ** = **k̂**, **ĵ**×**k̂** = **î**, **k̂**×**î** = **ĵ**. Sıra değişirse işaret değişir: **A**×**B** = −**B**×**A**.

## Bölüm 2: Doğru boyunca hareket

- Ortalama hız: v_ort = Δx / Δt. Ortalama ivme: a_ort = Δv / Δt.
- Anlık hız: v = dx/dt. Anlık ivme: a = dv/dt.
- Sabit ivme denklemleri:
  - v = v₀ + at
  - x = x₀ + v₀t + ½at²
  - v² = v₀² + 2a(x − x₀)
  - x − x₀ = ½(v₀ + v)t
- Serbest düşme: yukarı yön pozitifse a = −g.
- İvme sabit değilse: v = v₀ + ∫a dt, x = x₀ + ∫v dt.
- Grafikler: x–t eğimi hızdır. v–t eğimi ivmedir. v–t altındaki alan yer değiştirmedir.

## Bölüm 3: İki ve üç boyutta hareket

- **v** = d**r**/dt, **a** = d**v**/dt. Hız yörüngeye teğettir.
- Eğik atış (x₀ = y₀ = 0, fırlatma açısı α₀):
  - v₀x = v₀ cos α₀, v₀y = v₀ sin α₀
  - x = v₀x t, vx = v₀x (değişmez)
  - y = v₀y t − ½gt², vy = v₀y − gt
- Yatay zeminde: tepe yüksekliği h = v₀y² / (2g), uçuş süresi t = 2v₀y / g, menzil R = v₀² sin(2α₀) / g.
- Düzgün çembersel hareket: a_rad = v² / R = 4π²R / T², v = 2πR / T. İvme merkeze doğrudur.
- Düzgün olmayan çembersel hareket: a_rad = v² / R ve a_tan = d|v|/dt. Toplam a = √(a_rad² + a_tan²).
- Bağıl hız: **v**(P/A) = **v**(P/B) + **v**(B/A).

## Bölüm 4: Newton yasaları

- 1. yasa: Σ**F** = 0 ise hız sabittir (cisim durur ya da düz çizgide sabit süratle gider).
- 2. yasa: Σ**F** = m**a**. Bileşen bileşen yaz: ΣFx = max, ΣFy = may.
- Ağırlık: w = mg.
- 3. yasa: **F**(A'nın B'ye) = −**F**(B'nin A'ya). İki kuvvet farklı cisimlere etkir.

## Bölüm 5: Newton yasalarının uygulamaları

- Denge: ΣFx = 0, ΣFy = 0.
- Eğik düzlem (açı θ): ağırlığın düzleme paralel bileşeni mg sin θ, dik bileşeni mg cos θ.
- Görünür ağırlık (asansör): n = m(g + ay).
- Kinetik sürtünme: fk = μk n.
- Statik sürtünme: fs ≤ μs n. Cisim kaymıyorsa fs dengeyi sağlayan değerdir, μs n değildir.
- Sürtünmeli eğik düzlemde aşağı kayma: a = g(sin θ − μk cos θ).
- Kaymanın başladığı açı: tan θ = μs.
- Çembersel dinamik: ΣF_merkez = m v² / R.
- Sürtünmesiz eğimli viraj: tan β = v² / (gR).
- Düz viraj, kaymadan en büyük sürat: v = √(μs g R).
- Düşey çemberin tepesinde en küçük sürat (ip ya da ray): v = √(gR).
- Konik sarkaç: tan β = v² / (gR), periyot T = 2π√(L cos β / g).

## Bölüm 6: İş ve kinetik enerji

- Sabit kuvvetin işi: W = F s cos φ = **F**·**s**.
- Kinetik enerji: K = ½mv².
- İş–enerji teoremi: W_top = K₂ − K₁.
- Değişken kuvvet: W = ∫Fx dx (F–x grafiğinin altındaki alan).
- Yay: Fx = kx (yayı germek için gereken kuvvet). Yayı 0'dan x'e germek için yapılan iş ½kx².
- Güç: P_ort = ΔW / Δt, P = dW/dt = **F**·**v**. 1 W = 1 J/s.

## Bölüm 7: Potansiyel enerji ve enerji korunumu

- Yerçekimi potansiyel enerjisi: U_grav = mgy. W_grav = mgy₁ − mgy₂ = −ΔU_grav.
- Yay potansiyel enerjisi: U_el = ½kx². W_el = ½kx₁² − ½kx₂².
- Yalnız korunumlu kuvvetler iş yapıyorsa: K₁ + U₁ = K₂ + U₂.
- Başka kuvvetler de iş yapıyorsa: K₁ + U₁ + W_diğer = K₂ + U₂.
- Sürtünme işi: W_f = −fk s (yol boyunca, her zaman negatif).
- Genel enerji korunumu: ΔK + ΔU + ΔU_iç = 0.
- Potansiyelden kuvvet: Fx = −dU/dx. Üç boyutta **F** = −(∂U/∂x **î** + ∂U/∂y **ĵ** + ∂U/∂z **k̂**).
- Denge noktaları: dU/dx = 0. U minimumsa kararlı, maksimumsa kararsız.
- Enerji diyagramı: K = E − U. Cisim U > E olan bölgeye giremez; U = E olan yerde döner.
